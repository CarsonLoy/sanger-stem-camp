# Sanger STEM Camp Playbook

A practical, step-by-step guide for reproducing or adapting the free, three-day Sanger STEM Camp.

## Start here

1. Read `PROJECT-BRIEF.md`.
2. Read `AGENTS.md`.
3. Review `docs/CONTENT-INVENTORY.md`.
4. Give Codex the prompt in `CODEX-START-PROMPT.md`.
5. Keep all unverified facts marked as `TODO`.

The repository is intentionally content-first. The website framework should present these source files clearly without inventing details.
